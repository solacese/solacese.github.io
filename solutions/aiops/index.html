How It Works

AI Agents That Already Know Your Stack

Solace AIOps is a set of agents and workflows on Solace Agent Mesh. Every system you run gets its own agent, connected over Solace's event mesh.

01

Connect

Kubernetes, Postgres, Redis, Kafka, Elasticsearch and Solace each get an agent that knows how to read live state. A knowledge agent learns how your company works: your runbooks, your onboarding guides, who owns what.

Agents reach each system through MCP, the open Model Context Protocol, including Solace's own open-source broker MCP server.

Use any model and any cloud, and plug in whatever your infrastructure looks like.

02

Investigate and Resolve

Agents check live state across the stack and pull the metrics and logs that matter. Minutes later you get the answer: yesterday's deploy leaked connections and drained the Postgres pool, so new pods couldn't connect. Then the fix.

03

Ground and Approve

Every answer is grounded in official vendor documentation and your own company knowledge, with a citation for every claim. Every step is traceable. Once a human approves, the answer lands back on the ticket.

04

Repeat

For the issues you see every week, predetermined workflows run the same steps in the same order, every time. They're repeatable, auditable and cheaper than open-ended reasoning.

05

Control and Improve

The usage dashboard shows what every agent and workflow costs, and lets you set monthly caps. Users rate every answer as it arrives, so you see quality start to drift long before it becomes a problem.
